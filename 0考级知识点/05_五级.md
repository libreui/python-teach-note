### 1 文件操作（26 分）
- 文件分类
  - 文本文件：按字符存储，如 `.txt`、`.csv`，读写要指定编码
  - 二进制文件：按字节存储，如 `.jpg`、`.mp3`，用 `rb` / `wb`
- 编码
  - 常用 `encoding="utf-8"`；Windows 记事本默认可能是 GBK
  - 存的编码与读的编码不一致 → 乱码或 `UnicodeDecodeError`
- 打开与关闭
  - `f = open(文件名, 模式, encoding="utf-8")` …… `f.close()`
  - 推荐 `with open(文件名, 模式, encoding="utf-8") as f:`，代码块结束自动关闭，出异常也能关
- 打开模式
  - `r`：只读，默认模式，文件不存在报 `FileNotFoundError`
  - `w`：只写，文件已存在会**清空重写**，不存在则新建
  - `a`：追加，在文件末尾写，不清空
  - `r+`：读写，指针在开头
  - `rb` / `wb` / `ab`：二进制读 / 写 / 追加
- 读取
  - `f.read()`：读全部，返回字符串，大文件慎用
  - `f.read(n)`：读 n 个字符
  - `f.readline()`：读一行，含行末 `\n`
  - `f.readlines()`：读全部行，返回列表，每个元素带 `\n`
  - `for line in f:`：逐行遍历，最省内存
- 写入
  - `f.write(字符串)`：不自动换行，要手动加 `"\n"`
  - `f.writelines(列表)`：批量写入，同样不自动换行
  - 写入数字要先 `str()` 转换
- 定位
  - `f.tell()`：当前指针位置
  - `f.seek(偏移量, 起点)`：移动指针，起点 0 文件头、1 当前位置、2 文件尾
  - 文本模式下按字节精确跳转不可靠，需要精确跳转请用二进制模式
- 一维数据的表示与存储
  - 表示：列表 `[90, 85, 77]`
  - 存：每行一个元素，`f.write("\n".join(map(str, 列表)))`
  - 读：`f.read().split("\n")` 后逐项 `strip()`，再按需 `int()` / `float()`
  - 注意：读回来都是字符串，参与计算必须转换
- 二维数据的表示与存储
  - 表示：列表套列表 `[["姓名", "语文", "数学"], ["张三", 90, 88]]`
  - 存：每行用英文逗号连接，形成 CSV 格式
  - 读：逐行 `line.strip().split(",")`，得到二维列表
  - 注意：末尾空行要过滤；表头行要单独处理；数值列要转换
- 易错
  - 用 `w` 模式打开想看看内容，结果文件被清空
  - `write(123)` → TypeError，必须写字符串
  - 忘了 `close()`，内容可能没落盘
  - 中文路径 / 中文内容没指定 `encoding`

### 2 数据处理 pandas（16 分）
- 两个核心结构
  - `Series`：带标签的一维数组
  - `DataFrame`：二维表格，有行索引和列名
- 导入：`import pandas as pd`
- 创建
  - `pd.DataFrame({"姓名": ["张三", "李四"], "分数": [90, 85]})`
  - `pd.DataFrame([[1, 2], [3, 4]], columns=["A", "B"])`
- 读取
  - `pd.read_csv("data.csv", encoding="utf-8")`
  - `pd.read_excel("data.xlsx")`（需先装 openpyxl）
- 查看
  - `df.head()` / `df.tail()`：前 / 后几行
  - `df.shape`：行列数；`df.columns`：列名；`df.index`：行索引
  - `df["列名"]`：取一列（Series）；`df[["A", "B"]]`：取多列
- 取值定位
  - `df.loc[行标签, 列名]`：按标签取
  - `df.iloc[行号, 列号]`：按位置取
  - `df[df["分数"] > 80]`：按条件筛选
- 统计（大纲明确要求）
  - `count()`：非空值个数
  - `sum()`：求和
  - `mean()`：平均值（自动跳过缺失值）
  - `max()` / `min()`：最大 / 最小
  - `df.groupby("班级")["分数"].mean()`：分组求平均
  - 扩展：`value_counts()` 值计数、`describe()` 统计摘要
- 整理
  - `sort_values("分数", ascending=False)`：排序，默认升序
  - `drop("列名", axis=1)`：删列；`drop(行标签, axis=0)`：删行
  - `insert(位置, "列名", 值)`：插入新列
  - `rename(columns={"旧名": "新名"})`：改列名
  - `append(另一张表)`：追加行 —— **pandas 2.0 起已移除**，实际要用 `pd.concat([df1, df2])`
- 缺失值（扩展）
  - `df.isnull().sum()`：看每列空缺数
  - `df.dropna()`：删含空值的行；`df.fillna(0)`：填空值
- 易错
  - `drop` 忘了 `axis=1`，会去找行标签
  - 取值用 `df["列"]` 而不是 `df.列`，列名有空格或中文时更要用方括号
  - 统计前没看数据类型，字符串列 `sum()` 会拼接而不是求和
  - 中文列名带空格 / BOM，取值取不到

### 3 数据可视化 matplotlib（8 分）
- 导入：`import matplotlib.pyplot as plt`
- 中文显示（不设置会显示方块）
  - `plt.rcParams["font.sans-serif"] = ["SimHei"]`
  - `plt.rcParams["axes.unicode_minus"] = False`：负号正常显示
- 画布
  - `plt.figure(figsize=(6, 4))`：新建画布
- 常用图
  - `plt.plot(x, y)`：折线图，可加 `marker="o"`、`linestyle="--"`、`color="red"`
  - `plt.bar(x, height, color=)`：柱状图（竖）
  - `plt.barh(y, width)`：条形图（横）
  - `plt.scatter(x, y)`：散点图
- 图表要素
  - `plt.title("标题")`
  - `plt.xlabel("x 轴")`、`plt.ylabel("y 轴")`
  - `plt.xlim(0, 10)`、`plt.ylim(0, 100)`：坐标范围
  - `plt.legend(["图例"])`，配合绘图时的 `label=` 使用
- 显示与保存
  - `plt.show()`：显示图形，脚本里一般放最后
  - `plt.savefig("图.png", dpi=300)`：保存图片（扩展）
- 易错
  - 先 `show()` 再 `savefig()`，保存出来是空白图
  - 中文乱码 → 没设 rcParams，或设了但没重启内核
  - `plot(x, y)` 两个序列长度必须一致，否则报错

### 4 数据库 SQLite（20 分）
- 为什么要用：数据量大、要按条件查询、要长期保存，文本文件做不到
- 固定流程（六步）
  - 1 `import sqlite3`
  - 2 `conn = sqlite3.connect("student.db")`：连接，文件不存在会自动创建
  - 3 `cur = conn.cursor()`：创建游标
  - 4 `cur.execute(SQL 语句)`：执行
  - 5 取结果 / `conn.commit()`：增删改必须提交
  - 6 `cur.close()` → `conn.close()`：先关游标，再关连接
- 建表
  - `CREATE TABLE IF NOT EXISTS 表名 (id INTEGER PRIMARY KEY, name TEXT, score REAL)`
  - `IF NOT EXISTS` 避免重复建表报错
  - 常用类型：`INTEGER` 整数、`TEXT` 文本、`REAL` 浮点、`BLOB` 二进制
  - `PRIMARY KEY` 主键：唯一且非空
- 增删改
  - 插入单条：`INSERT INTO 表名 (name, score) VALUES (?, ?)`，参数用元组传入
  - 批量插入：`cur.executemany(SQL, [(), ()])`
  - 更新：`UPDATE 表名 SET score = ? WHERE name = ?`
  - 删除：`DELETE FROM 表名 WHERE id = ?`
  - 参数化写法（`?`）比字符串拼接更安全，也是考核常见写法
- 查询与取数
  - `SELECT * FROM 表名 WHERE score > 80 ORDER BY score DESC`
  - `cur.fetchone()`：取一条，返回元组；无数据返回 `None`
  - `cur.fetchmany(n)`：取 n 条，返回列表
  - `cur.fetchall()`：取全部，返回列表，每行是元组
  - 注意：游标读完就空了，再 fetch 取不到，需要重新 `execute`
- 完整示例（编程题标准写法）

```python
import sqlite3

conn = sqlite3.connect("student.db")
cur = conn.cursor()

cur.execute("CREATE TABLE IF NOT EXISTS student (id INTEGER PRIMARY KEY, name TEXT, score REAL)")
cur.execute("INSERT INTO student (name, score) VALUES (?, ?)", ("小明", 92.5))
conn.commit()

cur.execute("SELECT name, score FROM student WHERE score >= 60 ORDER BY score DESC")
for row in cur.fetchall():
    print(row[0], row[1])

cur.close()
conn.close()
```

- 易错
  - 增删改后忘 `commit()`，重连发现数据没存
  - `fetchone()` 用下标取列（`row[0]`），不是 `row["name"]`
  - SQL 语句里字符串拼接，遇到中文引号容易出错
  - 少写 `close()`，Windows 下文件被占用，删不掉

### 5 计算思维与编程题（30 分）
- 本级 3 道编程题通常落在：文件读写统计、pandas 处理、数据库查询、可视化
- 通用四步法
  - 读数据：`open()` / `read_csv()` / `SELECT`
  - 处理：统计、分组、排序、转换
  - 输出：`print()` / 写文件 / 画图
  - 检查：空行、类型转换、编码、格式
- 典型题型
  - 读成绩 CSV，求每科平均分并写回文件
  - 读文本日志，统计词频前 10
  - 从 SQLite 取数据，按班级分组求平均并画柱状图
  - 读写二维数据表，按条件筛选后另存
- 评分关注点：数据读取正确、结果正确、格式规范、异常处理（文件不存在 / 空数据）

## Python三级考试知识点掌握

> 依据《青少年软件编程（Python）等级考试大纲（2026 年修订版）》三级整理。
> 核心知识点：推导式、常用内置函数、算法（解析 / 枚举 / 排序）、数制转换。
> 2026 版把“推导式 + 序列解包切片”正式纳入本级，是本级最大的新增点。

### 1 编码数制（10 分）
- 四种进制
  - 二进制：`0b1010`，逢二进一，位权 2^n
  - 八进制：`0o17`，逢八进一
  - 十进制：日常写法
  - 十六进制：`0x1F`，0-9 加 A-F，A 表示 10
- 转换函数
  - `bin(n)`：十进制 → 二进制字符串，**带 `0b` 前缀**
  - `oct(n)`：十进制 → 八进制字符串，带 `0o` 前缀
  - `hex(n)`：十进制 → 十六进制字符串，带 `0x` 前缀
  - `int("1010", 2)`：二进制 → 十进制
  - `int("17", 8)`：八进制 → 十进制
  - `int("1f", 16)`：十六进制 → 十进制（不区分大小写）
  - `int("0b1010", 2)` 也能识别前缀
- 手算方法
  - 十进制转二进制：除 2 取余，余数倒序排列
  - 二进制转十进制：按权展开，如 `1011` = 8 + 0 + 2 + 1 = 11
  - 二进制 ↔ 八进制：三位一组；二进制 ↔ 十六进制：四位一组
- 相关概念
  - 编码：字符与数字的对应规则，如 ASCII、Unicode
  - `ord("A")` → 65，`chr(65)` → `"A"`，大小写码值相差 32
- 易错
  - `bin(10)` 得到 `"0b1010"`，不是 `"1010"`；要纯数字位需 `bin(10)[2:]`
  - 进制转换的结果是字符串，不能直接参与算术
  - `int("12a", 16)` 合法，`int("12a", 10)` 报 ValueError

### 2 推导式（12 分）
#### 列表推导式
- 格式 `[表达式 for 变量 in 可迭代对象 if 条件]`
- 基础：`[x * x for x in range(1, 6)]` → `[1, 4, 9, 16, 25]`
- 带条件：`[x for x in range(1, 11) if x % 2 != 0]` → 1 到 10 的奇数
- 双层：`[i * j for i in range(1, 4) for j in range(1, 4)]`
- 带 if-else：`["偶" if x % 2 == 0 else "奇" for x in range(5)]`
  - 注意：`if...else` 写在**表达式位置**，`if` 过滤写在**末尾**
- 与 for 循环等价，但更简洁；数据量大时内存占用与循环相当

#### 字典推导式
- 格式 `{键表达式: 值表达式 for 变量 in 可迭代对象}`
- `{x: x ** 2 for x in range(1, 5)}` → `{1: 1, 2: 4, 3: 9, 4: 16}`
- 键值互换：`{v: k for k, v in d.items()}`
- 配合 zip：`{k: v for k, v in zip(keys, values)}`
- 带条件：`{k: v for k, v in d.items() if v >= 60}`

#### 生成器推导式（生成器表达式）
- 格式用**圆括号** `(x for x in range(10))`
- 特点：惰性求值，用一个算一个，不占内存，适合大数据
- 取值方式：`next()` 逐个取；`list()`、`sum()`、`max()` 一次性消费
- **只能遍历一次**，第二次就空了
- 与列表推导式对比：`[x for x in range(10)]` 立即生成完整列表；`(x for x in range(10))` 返回生成器对象

#### 序列解包
- 一对一：`a, b = 1, 2`
- 交换：`a, b = b, a`
- 星号收集：`first, *rest = [1, 2, 3, 4]` → first=1，rest=[2, 3, 4]
- 函数传参：`print(*[1, 2, 3])` 等价于 `print(1, 2, 3)`
- 字典解包：`{**d1, **d2}` 合并（后者覆盖前者）
- 易错：左右个数不一致会 ValueError，除非用 `*`

#### 切片
- 格式 `序列[开始:结束:步长]`，**包头不包尾**
- `s[1:4]` 取下标 1、2、3
- 省略写法：`s[:3]` 从头取、`s[3:]` 取到尾、`s[:]` 复制
- 负索引：`s[-3:]` 取最后三个
- 负步长：`s[::-1]` 反转；`s[5:1:-1]` 从 5 倒着取到 2
- 切片赋值（仅列表支持）：`a[1:3] = [9, 9]`，长度可不等
- 字符串、元组切片只读，不能赋值

### 3 解析算法（8 分）
- 特征：按数学公式或确定的规律直接求解，不靠逐个试
- 三要素：已知条件 → 公式/递推关系 → 结果
- 典型例子
  - 求圆面积、三角形面积、平均数
  - 鸡兔同笼：设头 h、脚 f，兔 = `(f - 2*h) // 2`，鸡 = `h - 兔`
  - 阶乘、斐波那契（递推式 `f(n) = f(n-1) + f(n-2)`）
  - 等差数列求和、复利计算
- 实现要点
  - 先把公式写清楚，再翻译成表达式
  - 注意整除 `//` 与浮点 `/` 的选择
  - 递推要有初始值（边界）
- 易错：把解析算法写成枚举（能用公式一步算出，就不必循环试）

### 4 枚举算法（18 分）
- 特征：在有限范围内**逐个列举**候选，逐个判断是否满足条件
- 三要素
  - 枚举范围：不重、不漏
  - 判断条件：能明确判定真假
  - 输出：找到即输出，或统计个数
- 典型例子
  - 百钱买百鸡：三重循环，`5*x + 3*y + z/3 == 100` 且 `x+y+z == 100`
  - 水仙花数：三位数，各位立方和等于本身
  - 素数判断：`for i in range(2, int(n**0.5)+1)` 试除
  - 猜数字、穷举密码、找满足条件的整数
- 优化手段
  - 缩小范围（如鸡最多 20 只）
  - 找到唯一解就 `break`
  - 用整除代替浮点比较，避免精度问题
- 易错
  - 范围边界写错（`range(1, 100)` 取不到 100）
  - 多重循环里变量名重复，内层覆盖外层

### 5 排序算法（32 分）
#### 冒泡排序
- 思路：相邻两两比较，大的往后换，每轮把当前最大“冒”到末尾
- 轮数：n 个元素最多 n-1 轮
- 实现：双层循环，外层控制轮数，内层控制比较范围（每轮少比一个）
- 优化：某轮一次交换都没发生，说明已有序，直接结束
- 时间复杂度 O(n²)，空间 O(1)，**稳定**

#### 选择排序
- 思路：每轮在未排序区找最小（大）值，与未排序区第一个位置交换
- 轮数：n-1 轮，每轮只交换一次
- 时间复杂度 O(n²)，空间 O(1)，**不稳定**（交换会打乱相等元素的相对顺序）
- 与冒泡的区别：冒泡靠相邻交换，选择靠“记录下标再交换”

#### 插入排序
- 思路：像摸扑克牌，把当前元素插入前面已排好的序列
- 实现：从第 2 个元素开始，向前比较并后移，找到位置插入
- 时间复杂度 O(n²)，最好情况（接近有序）O(n)，空间 O(1)，**稳定**

#### 三种排序对比

| 算法 | 平均时间 | 最好情况 | 稳定性 | 交换次数 | 特点 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n)（优化后） | 稳定 | 多 | 每轮冒出极值，代码最易写 |
| 选择 | O(n²) | O(n²) | 不稳定 | 少（每轮 1 次） | 交换少，适合交换代价大的场景 |
| 插入 | O(n²) | O(n) | 稳定 | 中等 | 接近有序时最快，适合小规模 |

- 易错
  - 冒泡内层范围写成 `range(n)` 会越界
  - 选择排序记录的是**下标**，最后再交换，不能边比较边换
  - 插入排序移动的是元素，不是交换

### 6 核心内置函数（20 分）
> 大纲要求掌握“常用核心内置函数”，本级重点为下列 32 个。

#### 数学运算类（7 个）
- `abs(x)`：绝对值
- `divmod(a, b)`：返回 `(商, 余数)` 元组
- `max()` / `min()`：可传多个参数，也可传一个可迭代对象
- `round(x, n)`：四舍五入保留 n 位；注意“银行家舍入”，`round(2.5)` 得 2
- `sum(序列, 起始值)`：求和，只能用于数字
- `pow(a, b, mod)`：幂运算，三参数时取模

#### 类型转换类（14 个）
- `bool()` `int()` `float()` `str()`
- `ord(c)`：字符 → 码值；`chr(n)`：码值 → 字符
- `bin()` `oct()` `hex()`：十进制 → 二 / 八 / 十六进制字符串
- `tuple()` `list()` `dict()` `set()`：容器互转
  - `list("abc")` → `['a','b','c']`；`set([1,1,2])` → `{1,2}`
- `enumerate(序列, start=0)`：返回 `(索引, 元素)`，常用于带序号遍历

#### 序列操作类（6 个）
- `all()`：全为真才为真，空序列返回 True
- `any()`：有一个为真即为真，空序列返回 False
- `filter(函数, 序列)`：保留函数返回 True 的元素，返回迭代器
- `map(函数, 序列)`：逐个映射，返回迭代器；多序列可并行
- `next(迭代器, 默认值)`：取下一个值
- `sorted(序列, key=, reverse=)`：返回**新列表**，不改原序列
  - `sorted(d.items(), key=lambda x: x[1], reverse=True)` 按值排序

#### 对象操作类（2 个）
- `type(obj)`：返回类型，如 `type(3)` → `<class 'int'>`
- `format(值, 格式)`：格式化，如 `format(3.14159, ".2f")` → `"3.14"`

#### 交互操作类（2 个）
- `print()` `input()`

#### 文件操作类（1 个）
- `open(文件名, 模式, encoding=)`：打开文件，返回文件对象

- 易错
  - `map` / `filter` / `zip` 返回的是迭代器，`print` 看不到内容，要 `list()` 转换
  - `sorted` 有返回值，`list.sort()` 是原地排序返回 None
  - `sum` 不能直接对字符串列表求和，要先转换

### 7 计算思维与 Debug（编程题 3 道）
- 本级编程题的常见落点：枚举求解、排序实现、推导式处理数据、数制转换
- Debug 常看报错类型
  - `SyntaxError`：语法写错，如少冒号、括号不配对
  - `IndentationError`：缩进不一致
  - `TypeError`：类型不匹配，如 `"1" + 1`
  - `ValueError`：值不合法，如 `int("abc")`
  - `IndexError`：下标越界
  - `NameError`：变量名没定义或拼错
- 检查方法
  - 用小数据手算一遍，对照程序输出
  - 在关键位置 `print` 中间结果
  - 排序题把每一轮结果写出来，验证边界
  - 循环题先确认起始值、终止值、步长

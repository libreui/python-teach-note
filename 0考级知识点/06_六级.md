# Python六级考试知识点掌握

> 依据《青少年软件编程（Python）等级考试大纲（2026 年修订版）》六级整理。
> 核心知识点：类与对象、数组、字符串、队列、栈、二叉树。
> 结构变化：旧版六级里的文件操作、SQLite、pandas、matplotlib 已整体下移到五级；本级主线是“面向对象 + 数据结构”。

## 1 类与对象（26 分）
- 为什么需要：把“数据”和“操作数据的方法”打包在一起，按现实事物建模
- 定义类
  - `class 类名():`，类名用大驼峰（如 `Student`）
  - 类体缩进，里面先写属性、再写方法
- 初始化方法
  - `def __init__(self, 参数1, 参数2):`
  - `self` 代表实例本身，必须是第一个参数（名字可以换，但约定叫 self）
  - 在 `__init__` 里写 `self.属性名 = 参数`，创建对象时自动执行
- 创建实例
  - `对象名 = 类名(参数)`，括号不能省，参数个数要与 `__init__` 对齐
  - 没写 `__init__` 也能创建实例，但不能带参数
- 属性与方法
  - 实例属性：`self.xxx`，每个对象各有一份
  - 类属性：写在类体里、方法之外，所有实例共享
  - 实例方法：`def 方法名(self):`，调用时写 `对象.方法名()`，self 自动传入
  - 方法内部访问自己的属性必须写 `self.属性名`，否则只是局部变量
- 继承
  - `class 子类(父类):`，子类自动拥有父类的属性和方法
  - `super().__init__(参数)`：调用父类初始化，子类补充自己的属性时常用
  - 方法重写：子类定义与父类同名的方法，会覆盖父类版本
  - `super().方法名()`：在子类里调用被覆盖的父类方法
- 封装（拓展，了解即可）
  - `_属性`：约定私有，只是提示，外部仍可访问
  - `__属性`：名称被改写为 `_类名__属性`，外部无法直接访问
  - `@property`、`@classmethod`、`@staticmethod`
- 常用魔术方法（拓展）
  - `__str__`：`print(对象)` 时的显示内容
  - `__len__`、`__repr__`
- 类的导入
  - `from 模块 import 类名`；或 `import 模块` 后用 `模块.类名()`
- 易错
  - 方法忘写 `self` 参数 → 调用时报“多传了一个参数”
  - `__init__` 写成 `_init_` 或 `init` → 不报错，但创建对象时不会被调用
  - `对象 = Student` 忘写括号 → 拿到的是类本身，不是实例
  - 方法里写 `name = 参数` 而不是 `self.name = 参数` → 属性没保存
  - 子类重写方法时忘了调 `super()`，父类的初始化没执行

## 2 数组（22 分）
- 概念
  - 一组**类型相同**、在内存中**连续存放**的数据
  - 通过下标随机访问，取第 i 个元素是 O(1)
  - Python 中通常用 `list` 承载数组，也可用 `array` 模块限定类型
- 特性
  - 有序、元素可重复、可通过下标修改
  - 插入 / 删除要移动元素，平均 O(n)
- 创建
  - `a = [1, 2, 3]`
  - `a = [0] * 10`：批量初始化
  - `a = [None for _ in range(n)]`：预分配
  - `array("i", [1, 2, 3])`：需 `import array`，`i` 表示整型
- 访问
  - `a[0]` 第一个、`a[-1]` 最后一个
  - `len(a)`、切片 `a[1:4]`
  - 越界抛 `IndexError`
- 插入
  - `a.append(x)`：末尾追加
  - `a.insert(i, x)`：指定位置插入，后面元素整体后移
  - `a + [x]`：生成新数组，不修改原数组
- 删除
  - `a.pop(i)`：删并返回该值，不写 i 删末尾
  - `a.remove(x)`：按值删第一个匹配项
  - `del a[i]`：按下标删除
- 合并与常用操作
  - `a + b`：生成新数组
  - `a.extend(b)`：原地合并
  - `a * 3`：重复
  - `a.sort()`：原地排序；`sorted(a)`：返回新数组
  - `a.reverse()`、`a.count(x)`、`a.index(x)`
- 二维数组
  - `m = [[1, 2], [3, 4]]`，取值 `m[i][j]` 是第 i 行第 j 列
  - 遍历：外层走行，内层走列
  - 创建陷阱：`[[0] * 3] * 2` 两行指向同一对象，改一行全变
  - 正确写法：`[[0] * 3 for _ in range(2)]`
- 易错
  - 边遍历边删除会漏元素 → 倒序遍历，或另建列表
  - `append([1, 2])` 加进去的是“一个列表元素”，`extend([1, 2])` 才是加两个元素
  - `sort()` 返回 None，写成 `a = a.sort()` 会得到 None

## 3 字符串（19 分）
- 概念与特性
  - 不可变：一旦创建，内容不能原地修改
  - 有序、可迭代，支持下标与切片
  - 任何“修改”本质上都是生成一个新字符串
- 创建
  - 引号、三引号、`str()`
  - `f"{变量}"` 格式化插入
  - `"a" + "b"` 拼接；`"a" * 3` 重复
- 访问
  - `s[0]`、`s[-1]`、`s[1:4]`、`len(s)`
  - 遍历：`for ch in s:`
- 插入与删除（本质是切片拼接）
  - 插入：`s[:i] + "x" + s[i:]`
  - 删除：`s[:i] + s[i+1:]`
  - 替换：`s.replace("旧", "新")`，默认全部替换，可传第三个参数限制次数
- 常用操作
  - 查找：`find()` 找不到返回 -1；`index()` 找不到报错；`count()`
  - 分割：`split(",")` → 列表；不传参数按空白分割
  - 拼接：`",".join(列表)`，列表元素必须都是字符串
  - 大小写：`upper()`、`lower()`、`title()`
  - 去空白：`strip()`、`lstrip()`、`rstrip()`
  - 判断：`startswith()`、`endswith()`、`isdigit()`、`isalpha()`
  - 格式化：`format()`；`f"{x:>6}"` 右对齐、`f"{x:.2f}"` 保留两位
- 综合应用
  - 回文判断：`s == s[::-1]`
  - 字符统计：`count()`，或用字典逐个累加
  - 反转、去重、排序：`"".join(sorted(set(s)))`
  - 中文字符串排序：按 Unicode 码位比较，用 `ord()` 可看码值
  - 编码：`ord()` / `chr()`，ASCII 中大小写相差 32
- 易错
  - 字符串没有 `sort()`、`reverse()`、`append()` 这些方法
  - `"3" + 3` 报 TypeError，要写 `"3" + str(3)`
  - `join` 的列表里有数字会报错，先 `map(str, ...)`
  - 不可变意味着 `s[0] = "x"` 直接报 TypeError

## 4 队列（17 分）
- 概念：先进先出（FIFO），像排队买票，先来先服务
- 特性
  - 只允许在**队尾**入队、在**队头**出队
  - 插入和删除分别发生在两端
- 基本操作
  - 入队 `enqueue(x)` / 出队 `dequeue()`
  - 取队头 `front()`、判空 `is_empty()`、长度 `size()`
- 实现一：列表
  - 入队 `q.append(x)`，O(1)
  - 出队 `q.pop(0)`，O(n)，后面元素整体前移
  - 判空 `len(q) == 0`
- 实现二：`collections.deque`（推荐）
  - `from collections import deque`
  - `q = deque()`；入队 `q.append(x)`；出队 `q.popleft()`，O(1)
- 实现三：用类封装（考纲要求“实现方法”，编程题常考）
  - 类里维护 `self.items = []`
  - `enqueue` 用 `append`，`dequeue` 用 `pop(0)`，出队前先判空
- 应用
  - 广度优先搜索（BFS）逐层扩散
  - 打印机任务排队、消息队列
  - 约瑟夫环（报数出列）
- 易错
  - 用 `pop()` 当出队 → 取的是队尾，队列变成了栈
  - 空队列出队抛 `IndexError`，要先判空
  - `deque` 没有切片，不能 `q[1:3]`

## 5 栈（8 分）
- 概念：后进先出（LIFO），像叠盘子，最后放的最先拿
- 特性：只允许在**栈顶**插入和删除
- 基本操作
  - 入栈 `push(x)`、出栈 `pop()`、取栈顶 `top()` / `peek()`
  - 判空 `is_empty()`、长度 `size()`
- 实现
  - 列表：入栈 `s.append(x)`，出栈 `s.pop()`，栈顶 `s[-1]`，均为 O(1)
  - 类封装：维护 `self.items = []`，方法内做判空
  - `deque` 也可：`append` / `pop`
- 应用
  - 括号匹配：左括号入栈，右括号与栈顶配对，最后栈空才算匹配
  - 进制转换：除基取余，余数入栈，再依次出栈
  - 表达式求值、浏览器后退、撤销操作（Ctrl+Z）
  - 函数调用栈、递归的本质
- 易错
  - 空栈 `pop()` 抛 `IndexError`
  - `pop()` 与 `pop(0)` 混用 → 栈变成队列
  - 括号匹配只判数量不判类型，`"(]"` 会误判为正确

## 6 二叉树（8 分）
- 树的基本术语
  - 根结点、父结点、子结点、兄弟结点、叶子结点
  - 结点的度：子结点个数；树的深度 / 高度：最大层数
- 二叉树概念
  - 每个结点最多两个子结点，分左、右，且**左右不能颠倒**
  - 满二叉树：每层结点数都达到最大
  - 完全二叉树：除最后一层外都满，最后一层从左往右连续排列
- 重要性质
  - 第 i 层最多 `2^(i-1)` 个结点（i 从 1 开始）
  - 深度为 k 的二叉树最多 `2^k - 1` 个结点
  - 叶子数 n0 与度为 2 的结点数 n2 满足 `n0 = n2 + 1`
  - 完全二叉树有 n 个结点时，深度为 `⌊log2 n⌋ + 1`
- 存储方式
  - 链式存储：结点类包含 `val`、`left`、`right`
  - 顺序存储（完全二叉树）：列表存放，下标 i（从 0 开始）的左孩子 `2i+1`、右孩子 `2i+2`、父结点 `(i-1)//2`
- 创建
  - 定义 `class Node:`，`Node(val)` 建结点，手动连 `left` / `right`
  - 按层序列表建树：用队列依次挂左右孩子，遇到 `None` 跳过
- 遍历（本级重点）
  - 前序：根 → 左 → 右（NLR）
  - 中序：左 → 根 → 右（LNR）；二叉搜索树的中序遍历是升序
  - 后序：左 → 右 → 根（LRN）
  - 层序：用队列逐层访问，本质是 BFS
  - 递归要点：先判空 `if root is None: return`，再按顺序递归左右子树
  - 非递归：前 / 中 / 后序用栈，层序用队列
- 应用
  - 表达式树求值、目录结构、哈夫曼编码、二叉搜索树查找
- 易错
  - 前中后序的“序”，指的是**根**被访问的时机
  - 只知道前序 + 后序，无法唯一确定一棵二叉树；前序 + 中序可以
  - 递归忘写终止条件 → 无限递归、栈溢出
  - 层序遍历用栈会退化成深度优先，必须用队列

## 7 数据结构与算法综合（编程题 30 分）
- 选结构的判断
  - 要“后进先出” → 栈；要“先进先出” → 队列
  - 要按下标随机访问 → 数组；要不可变文本处理 → 字符串
  - 要逐层扩散 → 队列 + 二叉树层序
  - 要“数据 + 行为”绑定 → 类与对象
- 复杂度速记
  - 列表尾部 `append` / `pop`：O(1)
  - 列表中间插入删除：O(n)；按下标查找：O(1)；按值查找：O(n)
  - 内置 `sorted`：O(n log n)
  - 遍历二叉树：O(n)
- 编程题常见组合
  - 类封装 + 队列 / 栈（模拟排队叫号、括号匹配）
  - 建二叉树 + 三种遍历输出
  - 数组 / 字符串处理 + 统计
  - 用类实现“学生成绩管理”，配合排序与筛选

## 一级知识点

> 依据《青少年软件编程（Python）等级考试大纲（2026 年修订版）》一级整理。
> 核心知识点：简单数学运算与 Turtle 库；结构要求：顺序 + 单分支。

### 编程环境（10 分）
- 常见 Python 编程环境
  - IDLE：Python 自带，安装即用，无需另装
  - thonny：面向初学者，界面简洁，适合课堂
  - Visual Studio Code：靠插件扩展，适合工程化项目
  - Jupyter Notebook：网页式，按单元格运行，适合数据分析
- Python 的两个版本
  - Python 2 与 Python 3，迭代方向为 Python 3
  - Python 2 已于 2020 年停止维护
  - 示例区别：`print "hello"` 是 Python 2 写法，Python 3 必须写成 `print("hello")`
- IDLE 的两种开发模式
  - 交互模式：提示符 `>>>`，逐行运行、即时看到结果
  - 脚本模式：新建文件 → 编写 → 保存 → 运行（F5）
  - 切换：`File → New File` 进入脚本模式，`Run → Run Module` 运行
- IDLE 的文件操作
  - 新建：`File → New File`
  - 保存：`Ctrl + S`，默认后缀 `.py`（不是 `.idle`）
  - 打开：`File → Open`，改完要重新保存再运行
- 易错点
  - 改完代码没保存就按 F5，运行的是上一次保存的旧代码
  - 在交互模式里写多行缩进程序容易乱，多行程序一律用脚本模式
  - 记事本能写代码但不能直接运行；Python 并非只有一种编程环境，自带的是 IDLE

### 编程基础（26 分）
- 程序的基本结构：输入 → 处理 → 输出
- 输出 `print()`
  - `print("hello")` 输出文本
  - `print(35 - 10)` 先算再输出 `25`；`print("35-10")` 输出字符串 `35-10`
  - `print(a, b)` 多个值用逗号分隔，输出时自动用空格隔开
- 输入 `input()`
  - 括号里的字符串是提示语，如 `input("请输入一个数：")`
  - **返回值永远是字符串**，参与数学运算前必须转换：`int(input())`、`float(input())`
  - 易错：`input()` 是用来接收数据的，不是输入指令
- 引号
  - 单引号 `'...'` 与双引号 `"..."` 等价，必须成对
  - 三引号 `'''...'''`：可跨行，常作多行字符串或多行注释
  - 易错：用了中文引号“ ”会报错；引号不成对会报错
- 变量
  - 赋值 `a = 10`；`=` 是赋值，`==` 才是判断相等
  - 变量不需要提前定义，第一次出现就是定义
  - 第二次赋值会覆盖前一次的值（旧值被删除）
  - 命名规则：字母、数字、下划线组成；不能数字开头；区分大小写；不能用保留字
- 常用保留字（不能当变量名）
  - 分支与循环：`if` `elif` `else` `for` `while` `break` `continue` `pass`
  - 逻辑与取值：`and` `or` `not` `in` `is` `True` `False` `None`
  - 定义与导入：`class` `def` `return` `import` `from`
  - 异常：`try` `except` `finally` `raise`
  - 易错：`abc` 不是保留字；`is` 是保留字
- 注释
  - 单行 `#`，`#` 之后的内容不参与运行
  - 多行用三引号

### 数据类型
> 属于「编程基础（26 分）」的考点。

#### 字符串 (str)
- 用引号引起来：`"Hello"`、`'你好'`
- 特性：不可变、有序，可用 `len()` 取长度
- 相加即拼接：`"python2" + "python3"` → `python2python3`

#### 数
- 整数（int）：`10`、`-3`
- 浮点数（float）：`3.14`、`1.0`

#### 布尔值（bool）
口诀: `0 或者 1`
`非0即为True`
`非空即为True`

- True (真)
- False (假)
- 参与运算时 True 当 1，False 当 0

#### 类型转换
- 强制转换：`int()` `float()` `str()` `bool()`
  - `int("12")` → 12；`int("3.5")` 会报错，要先 `float()` 再 `int()`
  - `str(10)` → `"10"`；`float("3.14")` → 3.14
  - `bool(0)`、`bool("")`、`bool([])` 都是 False；`bool("0")` 是 True（非空字符串）
- 隐式转换（自动发生）
  - `1 + 2.0` → 3.0，int 自动提升为 float
  - `True + 1` → 2
  - 字符串不会自动转成数字：`"1" + 1` 直接报 TypeError

### 运算符
> 属于「数学运算（30 分）」的考点。

#### 算术运算符
- 加法 `+`
- 减法 `-`
- 乘法 `*`
- 除法 `/`
- 整除 `//`
- 取余(模) `%`
- 幂 `**`
- 注意：`/` 的结果一定是 float（`30 / 10` 得 `3.0`，不是 `3`）；`//` 向下取整
- 本级不涉及开方运算

#### 赋值运算符
- 赋值 `=`
- 加法赋值 `+=`
- 减法赋值 `-=`
- 乘法赋值 `*=`
- 除法赋值 `/=`
- 整除赋值 `//=`
- 取余赋值 `%=`
- 指数赋值 `**=`

#### 比较运算符（关系运算符）
- 等于 `==`
- 不等于 `!=`
- 大于 `>`
- 小于 `<`
- 大于等于 `>=`
- 小于等于 `<=`
- 是 `is`
- 不是 `is not`
- 比较的结果是 bool：`b != a` 得到 True / False
- `is` 判断“是不是同一个对象”，与 `==` 判断“值是否相等”不同，别混用

#### 逻辑运算符
- `and` 与：两侧都为真才为真，前假即假（短路）
- `or` 或：有一个为真即真，前真即真（短路）
- `not` 非：取反，`not True` → False
- 易错：`and` / `or` 返回的不一定是 True/False，而是决定结果的那个操作数
  - `0 and 10` → `0`；`3 and 10` → `10`
  - `0 or 10` → `10`；`3 or 10` → `3`

#### 优先级（高 → 低）
`**` → 正负号 → `* / // %` → `+ -` → 比较运算 → `not` → `and` → `or`
- 括号最优先，不确定就加括号
- 易错：`a * b - 5` 不会把 `b - 5` 先算

### 单分支结构
> 属于「计算思维（10 分）」的考点。本级只考顺序 + 单分支，不考 `else`、`elif` 和循环。

- 语句格式 `if 条件:` 换行缩进写语句块
- 要点
  - 条件后面的冒号 `:` 不能少
  - 语句块统一缩进（4 个空格），同一块缩进必须一致
  - 条件的结果是 bool：`if 0:` 不执行，`if "":` 不执行，`if "0":` 会执行
- 常见写法
  - 判断大小：`if a > b:` 输出大数
  - 判断奇偶：`if n % 2 == 0:` 输出偶数
  - 判断闰年：`if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:`
- 易错
  - 把判断写成 `if a = 10:` → 语法错误，判断相等必须用 `==`
  - 缩进错位 → `IndentationError`，`print` 跑到 `if` 外面会无条件执行

### 绘图Turtle（24 分）
- 导入库文件
  - `import turtle`，调用时写 `turtle.forward(100)`
  - `from turtle import *`，可直接写 `forward(100)`
- 画布
  - `turtle.setup(width, height, startx, starty)`：设置窗口大小与位置
  - `turtle.screensize(w, h, bg)`：设置画布大小与背景（不是画笔控制命令）
  - `turtle.bgcolor("white")`：背景色
  - 坐标系：画布正中心为 `(0, 0)`，海龟初始朝向正右（东）
  - `turtle.done()`：保留窗口，程序结束不闪退
  - `turtle.clear()`：清空画面，海龟位置与状态不变
  - `turtle.reset()`：清空画面并把海龟复位到初始状态
- 画笔
  - `turtle.penup()` / `up()`：提笔，移动不留痕
  - `turtle.pendown()` / `pd()`：落笔，移动画线
  - `turtle.pensize(宽度)`：画笔粗细
  - `turtle.pencolor("red")`：画笔颜色
  - `turtle.fillcolor("yellow")`：填充颜色
  - `turtle.color("red", "yellow")`：第一个是画笔色，第二个是填充色
  - `turtle.color("red")` 只传一个参数时，画笔色与填充色同时改变
- 运动
  - `turtle.forward(d)` / `fd(d)`：沿当前朝向前进 d 像素
  - `turtle.backward(d)` / `bk(d)`：后退
  - `turtle.left(角度)` / `lt()`：左转（逆时针）
  - `turtle.right(角度)` / `rt()`：右转（顺时针）
  - `turtle.goto(x, y)`：移动到指定坐标，不改变朝向
  - `turtle.setheading(角度)` / `seth()`：设置绝对朝向，0 东、90 北、180 西、270 南
  - `turtle.home()`：回到原点并朝东
- 画图
  - `turtle.dot(直径, 颜色)`：画点
  - `turtle.circle(r)`：画半径 r 的圆，圆心在画笔左侧
  - `turtle.circle(r, extent)`：画弧，`circle(120, 180)` 是半径 120 的半圆
  - 填充：`begin_fill()` 与 `end_fill()` 成对使用，中间画闭合图形
- 易错点
  - “到坐标再转向”：顺序是先 `goto()` 后 `left()`，颠倒过来朝向就不同
  - 不抬笔直接移动，会画出多余的线
  - 画圆时圆心在画笔左侧，用 `goto` 找圆心容易偏，常用“先移到最低点”的写法
  - `screensize()` 属于画布命令，不算画笔控制
  - 画正方形内切圆：正方形边长 = 圆直径，先算好中心坐标

### 计算思维（10 分）
- 顺序执行：自上而下逐行运行，前一步的结果给后一步用
- 单分支：满足条件才执行语句块
- 表达式求值顺序：先括号，再算术，再比较，最后逻辑
  - 示例：`3 > 4 or 4 < 3 and 1 == 1`
  - 先算 `and`：`False and True` → `False`
  - 再算 `or`：`False or False` → `False`
  - 注意：官方样题该题给出的答案是 `D`（4），但按 Python 短路求值实际运行结果是 `False`，以实际运行结果为准
- 常见题型
  - 给变量求表达式结果，重点区分 `/` 与 `//`
  - 判断一段 turtle 代码画出什么图形、海龟最终朝哪
  - 输入两个数，输出和与积（`input()` 必须转换类型）
  - 两个变量交换：`a, b = b, a`

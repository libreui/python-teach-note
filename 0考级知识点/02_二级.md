## Python二级考试知识点掌握

> 依据《青少年软件编程（Python）等级考试大纲（2026 年修订版）》二级整理。
> 核心知识点：核心数据类型（列表、元组、字符串、字典）+ 流程控制（分支、循环）。
> 2026 版修订说明未涉及本级，考试标准与 2026 正式大纲一致，因此内容按正式大纲逐条对齐。

### 1 列表（21 分）
- 概念与特性
  - 用方括号 `[]` 表示，元素之间用逗号分隔
  - **有序**：元素按插入顺序排列，每个元素有唯一索引
  - **可变**：可以增、删、改，操作直接作用在原列表上
  - 元素可重复、类型可不同、可嵌套（列表里放列表）
- 声明
  - `a = [1, 2, 3]`、`a = []` 空列表
  - `a = list("abc")` → `['a', 'b', 'c']`
  - `a = list(range(5))` → `[0, 1, 2, 3, 4]`
- 访问
  - 下标从 0 开始：`a[0]` 第一个；负索引 `a[-1]` 最后一个
  - 切片 `a[1:4]`，包头不包尾
  - 越界抛 `IndexError`
- 更新
  - 按下标改：`a[0] = 100`
  - 切片赋值：`a[1:3] = [9, 9]`，赋的值长度可以不等
  - 嵌套取值：`a[0][1]`
- 获取元素个数
  - `len(a)`
- 判断是否有某个元素
  - `100 in a` → True / False，`not in` 取反
  - 注意 `in` 判断的是“值是否存在”，不是下标
- 遍历
  - `for x in a:` 取元素
  - `for i in range(len(a)):` 取下标
  - `for i, x in enumerate(a):` 同时拿下标和元素
- 添加
  - `a.append(x)`：末尾追加一个元素
  - `a.insert(i, x)`：指定位置插入，后面元素后移
  - `a.extend(b)`：把另一个序列的元素逐个加进来
  - `a + b`：生成新列表，不修改原列表
- 删除
  - `del a[i]`：按下标删
  - `a.pop(i)`：删并返回该值，不写 i 删末尾
  - `a.remove(x)`：按值删第一个匹配项，值不存在报 ValueError
  - `a.clear()`：清空
- 连接与重复
  - `a + b` 连接，`a * 3` 重复
- 排序
  - `a.sort()`：原地排序，返回 None
  - `a.sort(reverse=True)`：降序
  - `sorted(a)`：返回新列表，原列表不变
  - `a.reverse()`：原地反转
- 从别的类型转换
  - `list("abc")`、`list((1, 2))`、`list(range(3))`
  - `list("1,2,3".split(","))` 分割后转列表
- 易错
  - `a = a.sort()` 得到 None，原列表其实已经排好了
  - `[[0] * 3] * 2` 两行是同一个对象，改一行全变，要用推导式创建
  - 边遍历边删除会漏元素，应倒序遍历或另建列表
  - `append([1, 2])` 加的是“一个列表元素”，`extend([1, 2])` 才是两个元素

### 2 元组（10 分）
- 概念
  - 用圆括号 `()` 表示，元素用逗号分隔
  - **有序、不可变**：创建后不能增删改元素
- 声明
  - `t = (1, 2, 3)`、`t = ()` 空元组
  - **单元素元组必须带逗号**：`t = (1,)`；`t = (1)` 是整数，不是元组
  - `t = tuple([1, 2])` 由列表转换
- 访问
  - `t[0]`、`t[-1]`、切片 `t[1:3]`、`len(t)`
  - 遍历 `for x in t:`
  - 解包 `a, b, c = t`（三级会系统讲）
- 与列表的异同
  - 相同：有序、可索引、可切片、可遍历、元素可重复
  - 不同：元组不可变；元组可作字典的键，列表不行；元组占用空间更小、访问略快
- 变通修改（考纲明确要求）
  - 转成列表改完再转回：`t = tuple(list(t)[:1] + [9] + list(t)[2:])`
  - 用切片拼接：`t = t[:1] + (9,) + t[2:]`
  - 本质都是生成新元组，原元组不变
- 删除
  - `del t`：删除整个元组变量
  - 不能 `del t[0]`，元素不可删
- 易错
  - `t[0] = 1` 直接报 TypeError
  - `t = (1)` 得到 int，不是元组
  - 想“修改”元组，必须重新赋值一个新元组

### 3 字符串（15 分）
- 概念与特性
  - 用引号包裹，单引号、双引号等价，三引号可跨行
  - 不可变、有序、可迭代，任何修改都生成新字符串
- 声明
  - `s = "hello"`、`s = '你好'`、`s = """多行文本"""`、`s = str(123)`
- 访问
  - `s[0]`、`s[-1]`、切片 `s[1:4]`
  - 获取长度 `len(s)`
  - 遍历 `for ch in s:`
- 分割
  - `s.split(",")`：按逗号切，返回列表
  - `s.split()`：不传参数，按空白（空格、换行、制表）切，并自动去掉空串
  - `s.split(",", 2)`：最多切 2 次
- 组合
  - `"".join(列表)`：把列表拼成字符串，元素必须都是字符串
  - `"-".join(["2026", "11", "21"])` → `"2026-11-21"`
  - `+` 拼接，`*` 重复
- 替换
  - `s.replace("旧", "新")`：默认全部替换，可传第三个参数限制次数
- 转义
  - `\n` 换行、`\t` 制表、`\\` 反斜杠、`\'` `\"` 引号
  - `r"C:\new"` 原始字符串，反斜杠不当转义
- 格式化
  - `%` 方式：`"%s 考了 %d 分" % (name, score)`
  - `format`：`"{} 考了 {} 分".format(name, score)`、`"{0:.2f}".format(3.14159)`
  - f-string：`f"{name} 考了 {score} 分"`，最常用
- 常用方法
  - `find()` 找不到返回 -1；`index()` 找不到报 ValueError
  - `count()` 统计出现次数
  - `upper()` / `lower()` 大小写
  - `strip()` 去两端空白，`lstrip()` / `rstrip()`
  - `startswith()` / `endswith()` 判断前后缀
  - `isdigit()` / `isalpha()` 判断字符类型
- 易错
  - 字符串没有 `append()`、`sort()`、`reverse()`
  - `"3" + 3` 报 TypeError，要 `"3" + str(3)`
  - `join` 的列表里混了数字会报错，先 `map(str, ...)`
  - 中文引号会导致语法错误

### 4 字典（10 分）
- 概念
  - 键值对（key: value）集合，用花括号 `{}` 表示
  - **键唯一**，重复赋值会覆盖；**键必须可哈希**（数字、字符串、元组可以，列表不行）
  - 3.7 起按插入顺序保存，但一般不依赖顺序
- 声明
  - `d = {"语文": 90, "数学": 88}`
  - `d = {}` 空字典
  - `d = dict(a=1, b=2)`、`d = dict([("a", 1), ("b", 2)])`
- 访问
  - `d["语文"]`：键不存在报 `KeyError`
  - `d.get("英语")`：不存在返回 None，不报错
  - `d.get("英语", 0)`：不存在返回指定默认值
- 获取元素个数
  - `len(d)`
- 判断键是否存在
  - `"语文" in d`：判断的是**键**，不是值
- 追加与修改
  - `d["英语"] = 95`：键不存在则新增，存在则覆盖
  - `d.update({"英语": 95, "物理": 80})`：批量新增或修改
  - `d.setdefault("英语", 0)`：键不存在时设默认值
- 删除
  - `d.pop("语文")`：删并返回值，键不存在报错
  - `d.pop("语文", None)`：不存在时返回默认值，不报错
  - `del d["语文"]`
  - `d.popitem()`：删掉最后一个键值对
  - `d.clear()`：清空
- 遍历
  - `for k in d:` 默认遍历键
  - `d.keys()`、`d.values()`、`d.items()` 分别取键、值、键值对
  - `for k, v in d.items():` 最常用
- 易错
  - 用不存在的键 `[]` 取值 → KeyError，不确定就用 `get()`
  - 列表当键 → TypeError（unhashable）
  - 遍历字典时增删键会报 RuntimeError，应先转成列表再改

### 5 流程控制（34 分）
- 选择结构
  - 单分支：`if 条件:` 加缩进语句块
  - 二分支：`if ...: ... else: ...`
  - 多分支：`if ...: elif ...: elif ...: else:`
  - 嵌套：if 里面再写 if，注意缩进层级
  - 条件表达式（三元）：`"及格" if score >= 60 else "不及格"`
- 循环结构
  - `for x in 序列:`：已知次数或已知序列时用
  - `for i in range(n):`：`range` 包头不包尾，`range(1, 5)` 是 1、2、3、4
  - `range(start, stop, step)`：步长为负可倒序
  - `while 条件:`：条件为真就循环，适合“不知道次数、知道终止条件”
  - 嵌套循环：外层控制行、内层控制列，常用于打印图形、乘法表
- 循环控制
  - `break`：跳出**当前这一层**循环
  - `continue`：跳过本次剩余语句，直接进入下一次
  - `for...else` / `while...else`：循环正常结束（没被 break）才执行 else
- 编程套路
  - 累加器：`s = 0` 后循环 `s += x`
  - 计数器：`c = 0`，满足条件就 `c += 1`
  - 求最值：先设第一个元素为最大/最小，再逐个比较
  - 标记法：`flag = True`，找到就改 False 并 `break`
  - 输入多组数据：`while True:` + `break`
- 易错
  - while 循环体里忘了改变循环变量 → 死循环
  - `break` 只能跳出最内层，嵌套循环要跳出全部得用标记或函数
  - `range(5)` 取不到 5；`range(5, 0)` 为空
  - for 循环里修改正在遍历的列表，结果不符合预期
  - 缩进错了，语句跑到循环外面，只执行一次

### 6 计算思维（10 分）
- 本级编程题 2 道，落点在“分支 + 循环”的组合
- 常见题型
  - 成绩等级判断（多分支）
  - 累加求和、求平均、统计个数
  - 判断素数、判断闰年、求最大公约数（循环版）
  - 打印图形（三角形、菱形、九九乘法表）
  - 猜数字、简单菜单循环
  - 列表/字典的增删查改小系统
- 评分关注点：输入输出正确、分支完整、循环边界正确、格式规范
- 检查方法
  - 用小数据手算一遍对照输出
  - 边界值单独试：0、1、最大值、空列表
  - 循环题先确认起始值、终止值、步长

## Python四级考试知识点掌握

> 依据《青少年软件编程（Python）等级考试大纲（2026 年修订版）》四级整理。
> 核心知识点：自定义函数、递归与递推、分治（对分查找）、算法效率、模块与常用标准库。
> 2026 版修订说明未涉及本级，考试标准与 2026 正式大纲一致，因此内容按正式大纲逐条对齐。

### 1 函数概念（16 分）
- 为什么用函数
  - 代码复用：同一段逻辑不用写两遍
  - 问题分解：把大问题拆成小步骤
  - 结构清晰：主程序只负责调用
- 定义与调用
  - `def 函数名(参数列表):` 换行缩进写函数体
  - 调用 `函数名(实参)`，括号不能省
  - 先定义后调用，函数不调用就不执行
- 参数
  - 位置参数：`def f(a, b)`，调用 `f(1, 2)`，按顺序对应
  - 关键字参数：`f(b=2, a=1)`，按名字对应
  - 默认参数：`def f(a, b=10)`，默认参数必须放在非默认参数之后
  - 可变参数：`*args` 收集成元组，`**kwargs` 收集成字典（了解）
- 返回值
  - `return 值`：结束函数并把值交回调用处
  - 没有 `return` 或只写 `return`：返回 `None`
  - 返回多个值：`return a, b`，本质是返回元组
  - `return` 之后的语句不会执行
- 变量作用域
  - 局部变量：函数内部定义的，函数结束就销毁
  - 全局变量：函数外部定义，函数内可读
  - 函数内修改全局变量需 `global` 声明（不推荐滥用）
  - 查找顺序 LEGB：局部 → 外层函数 → 全局 → 内置
- 匿名函数
  - `lambda 参数: 表达式`，只能写一个表达式，自带 return
  - 常配合 `sorted(key=...)`、`map()`、`filter()` 使用
- 易错
  - 函数名拼错或定义在调用之后 → `NameError`
  - `print` 和 `return` 混用：`print` 只是显示，`return` 才是把值交给调用方
  - 默认参数写成可变对象（如 `def f(a=[])`），多次调用会共用同一个列表
  - 函数内给参数重新赋值，不会影响函数外的同名变量

### 2 自定义函数（26 分）
- 创建步骤
  - 先想清楚：输入是什么（参数）、输出是什么（返回值）、中间做什么
  - 写 `def` 与缩进函数体，最后 `return` 结果
  - 在函数下面调用并测试
- 文档字符串
  - 函数体第一行写三引号说明，可用 `help(函数名)` 查看
- 参数传递的特点
  - 传的是对象的引用，不是复制
  - 传不可变对象（数字、字符串、元组）：函数内怎么改都不影响外部
  - 传可变对象（列表、字典）：函数内原地修改会影响外部，不想影响就传副本 `f(a[:])`
- 调用方式
  - 单独调用、赋值接收返回值、作为另一个函数的参数
  - 嵌套调用：函数里调另一个函数
  - 函数可以返回函数（了解）
- 编程题常见写法
  - 判断素数：`def is_prime(n):`
  - 求最大公约数：辗转相除，`def gcd(a, b):`
  - 成绩转等级：多分支 `def level(score):`
  - 列表统计：`def average(lst):`
  - 打印分隔线：`def line(n, ch="-"):`
- 易错
  - 忘写冒号、缩进不一致 → SyntaxError / IndentationError
  - 定义时写了参数，调用时少传 → TypeError
  - 函数内 `return` 写在循环里，只返回第一次的结果，需要循环结束后再 return
  - 有返回值却只用 `print` 输出，调用方拿到的还是 None

### 3 递归与递推（22 分）
- 递归三要素
  - 终止条件（边界）：什么时候不再调用自己
  - 递归表达式：自己调用自己，且规模必须变小
  - 结果回传：把子问题的结果组合成本问题的结果
- 典型递归
  - 阶乘 `f(n) = n * f(n-1)`，边界 `f(1) = 1`
  - 斐波那契 `f(n) = f(n-1) + f(n-2)`，边界 `f(1) = f(2) = 1`
  - 累加求和 `f(n) = n + f(n-1)`，边界 `f(1) = 1`
  - 汉诺塔：把 n-1 个盘先移到辅助柱，再移动最大盘，最后移回
  - 求最大公约数、进制转换、字符串反转
- 递归的代价
  - 每层调用占一个栈帧，Python 默认递归深度约 1000 层，超了报 `RecursionError`
  - 斐波那契这种“一个调用拆成两个”的写法会大量重复计算，n 大了非常慢
- 递推
  - 从已知的初值出发，用循环一步步推出后面的值
  - 例：斐波那契 `a, b = 1, 1` 后循环 `a, b = b, a + b`
  - 优点是效率高、不占调用栈；缺点是不如递归直观
- 递归与递推的转换
  - 递归向下“拆问题”，递推向上“推结果”
  - 递归改递推：把边界写成初值，把递归式写成循环体
  - 记忆化（缓存已算过的值）可救递归的效率，属拓展
- 对比

| 方式 | 实现 | 效率 | 风险 | 适合 |
|---|---|---|---|---|
| 递归 | 函数调用自身 | 有调用开销，易重复计算 | 层数过深栈溢出 | 结构天然分层的问题（树、汉诺塔） |
| 递推 | 循环 + 变量迭代 | 高 | 边界初值写错 | 有明显前后项关系的问题（数列、累加） |

- 易错
  - 忘写终止条件 → 无限递归
  - 递归后没有 `return`，上一层拿到 None，结果全错
  - 边界值写错（如 `f(0)` 写成 `f(1)`），结果整体偏移
  - 递归里用全局变量累加，多次调用结果会累加错

### 4 分治算法（18 分）
- 核心思想
  - 分解：把大问题切成规模更小的同类子问题
  - 解决：子问题小到可以直接求解
  - 合并：把子问题的解组合成原问题的解
- 分治与递归的关系
  - 分治是“思路”，递归是“实现手段”，分治一般用递归写
- 二分（对分）查找
  - **前提：数据必须有序**
  - 思路：取中间元素比较，比目标大就到左半边找，比目标小就到右半边找，每次砍掉一半
  - 循环写法：`low = 0`、`high = len(a) - 1`，`while low <= high:`，`mid = (low + high) // 2`
  - 命中返回 `mid`；`a[mid] < target` 时 `low = mid + 1`；否则 `high = mid - 1`
  - 找不到返回 `-1`
  - 递归写法：把 `low`、`high` 作为参数传入
  - 时间复杂度 O(log n)：100 万条数据最多约 20 次比较
- 其他分治例子（了解）
  - 归并排序：分成两半分别排序再合并
  - 快速排序：选基准值分区，两边分别递归
  - 求最大值、求幂、大整数乘法
- 易错
  - 数据没排序就二分 → 结果错误
  - 循环条件写成 `low < high`，会漏掉最后一个元素
  - `low = mid` / `high = mid` 没加 1 或减 1 → 死循环
  - `mid` 计算用 `/` 得到浮点数，要用 `//`
  - 找到后不返回，继续循环

### 5 算法效率（6 分）
- 两个概念
  - 时间复杂度：随数据规模增长，基本操作执行次数的增长趋势
  - 空间复杂度：随数据规模增长，额外占用存储的增长趋势
- 常见量级（由快到慢）
  - `O(1)` 常数：下标取值、判断奇偶
  - `O(log n)` 对数：二分查找、折半
  - `O(n)` 线性：一次遍历、单层循环
  - `O(n log n)`：归并排序、快速排序平均情况、内置 `sorted`
  - `O(n²)` 平方：双层循环、冒泡 / 选择 / 插入排序
  - `O(2^n)` 指数：朴素递归求斐波那契
- 怎么估算
  - 看循环层数：一层 O(n)，两层 O(n²)
  - 看是否每次折半：折半就是 log
  - 只看最高阶，忽略常数和低阶项：`3n² + 2n + 5` 记为 O(n²)
- 优化的常见手段
  - 用公式代替循环（解析算法）
  - 用二分代替顺序查找
  - 用字典 / 集合代替列表查找，把 O(n) 降到 O(1)
  - 缓存重复计算的结果
- 易错
  - 把执行时间当成复杂度，复杂度看的是“增长趋势”
  - 认为 O(n log n) 一定比 O(n²) 慢，n 很小时常数项影响大，但趋势上 O(n log n) 更优

### 6 库与模块（12 分）
- 基本概念
  - 模块：一个 `.py` 文件；包：装模块的文件夹（含 `__init__.py`）
  - 标准库：Python 自带，装了 Python 就能用
  - 第三方库：需要另外安装
- 导入方式
  - `import math` → 用 `math.sqrt(9)`
  - `from math import sqrt` → 直接用 `sqrt(9)`
  - `import math as m` → 用 `m.sqrt(9)`
  - `from math import *`：一次导入全部，容易命名冲突，不推荐
- 安装方式（考纲提到）
  - `pip install 库名`：最常用，联网从 PyPI 下载
  - `pip install 文件名.whl`：安装 wheel 包，适合离线环境
  - `.exe` 安装包：部分库提供，双击按向导安装
  - 安装失败常见原因：网络、权限、版本不匹配
- 常用标准库：`math`
  - `math.sqrt(x)` 平方根
  - `math.ceil(x)` 向上取整、`math.floor(x)` 向下取整
  - `math.pi` 圆周率、`math.e` 自然常数
  - `math.fabs(x)` 绝对值（返回 float）
  - `math.pow(x, y)` 幂（返回 float）
  - `math.gcd(a, b)` 最大公约数
- 常用标准库：`random`
  - `random.random()`：0 到 1 之间的浮点数，含 0 不含 1
  - `random.randint(a, b)`：a 到 b 的整数，**含两端**
  - `random.choice(序列)`：随机取一个元素
  - `random.sample(序列, k)`：随机取 k 个不重复元素
  - `random.shuffle(列表)`：原地打乱，返回 None
  - `random.uniform(a, b)`：区间内的随机浮点数
  - `random.seed(n)`：设随机种子，结果可复现，便于调试
- 易错
  - `import math` 后直接写 `sqrt(9)` → NameError
  - `random.randint(1, 10)` 能取到 10，与 `range` 的包头不包尾不同
  - `random.shuffle` 返回 None，写成 `a = random.shuffle(b)` 会得到 None
  - 模块名与变量名重名，把模块覆盖掉
  - 第三方库没装就 `import` → ModuleNotFoundError

### 7 计算思维与编程题（30 分）
- 本级 3 道编程题通常落在：自定义函数、递归 / 递推、二分查找
- 通用四步法
  - 读题：明确输入、输出、边界
  - 设计：判断用循环、递归还是二分
  - 实现：先写主体，再补边界处理
  - 验证：小数据手算对照，试边界值
- 典型题型
  - 用函数封装判断素数 / 求最大公约数 / 求阶乘
  - 递归求斐波那契、汉诺塔步数、累加和
  - 在有序列表中二分查找目标值，返回下标或 -1
  - 用 `random` 生成随机数做猜数字游戏
  - 用函数拆分一个较大的统计任务（求平均、求最值、分类统计）
- 评分关注点：函数定义与调用正确、返回值正确、递归有终止条件、边界处理、格式规范

# 飞机大战 需求文档

## 1. 项目概述

### 1.1 项目背景
"飞机大战"是一款基于 `pygame` 的纵向卷轴射击小游戏，作为 Python 游戏开发的学习与练习项目，演示精灵（Sprite）、精灵组（Group）、定时事件、碰撞检测等核心概念的工程化应用。

### 1.2 项目目标
- 实现一款可运行、可操作的纵向卷轴射击游戏 Demo；
- 采用面向对象 + 精灵架构，代码分层清晰、易于扩展。

### 1.3 目标用户
Python 学习者、游戏开发入门者（教学演示场景）。

## 2. 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows / macOS / Linux（支持 SDL 平台） |
| 运行环境 | Python 3.x |
| 依赖库 | pygame（`pip install pygame`） |
| 屏幕分辨率 | 480 × 700 |

## 3. 功能需求

### 3.1 基础功能（已实现）

| 编号 | 需求 | 说明 |
|------|------|------|
| F1 | 游戏窗口 | 480×700 窗口，60 FPS 刷新 |
| F2 | 滚动背景 | 背景图持续向下滚动，形成飞机向前飞行的视觉效果 |
| F3 | 英雄机控制 | 左右方向键控制英雄机水平移动，限制在窗口边界内 |
| F4 | 英雄机动画 | 英雄机双帧循环动画（me1/me2） |
| F5 | 发射子弹 | 按空格键在英雄机顶部发射子弹，子弹向上飞行 |
| F6 | 敌机生成 | 每 1 秒定时生成敌机（10% 概率生成大型敌机） |
| F7 | 敌机移动 | 敌机以随机/固定速度向下飞行，飞出屏幕自动销毁 |
| F8 | 子弹击中敌机 | 子弹与敌机矩形碰撞后：子弹销毁、敌机进入爆炸状态 |
| F9 | 敌机爆炸动画 | 敌机播放 3 帧爆炸动画后自动销毁 |
| F10 | 精灵回收 | 出屏、动画结束的精灵自动从组中移除，避免内存泄漏 |

### 3.2 操作需求

| 输入 | 行为 |
|------|------|
| `←` / `→` 键 | 英雄机左移 / 右移（按住持续移动） |
| `空格` 键 | 发射子弹 |
| 关闭窗口 | 退出游戏 |

### 3.3 表现需求
- 敌机爆炸时有连续动画帧过渡；
- 子弹、英雄机、敌机分层绘制（背景 → 敌机 → 英雄 → 子弹）。

## 4. 非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | 稳定运行于 60 FPS；精灵数量较多时不明显掉帧 |
| 可维护性 | 精灵逻辑封装于类中，主程序只做调度与事件处理 |
| 资源依赖 | 所有图片资源位于 `images/` 目录，缺图需能快速定位 |
| 可扩展性 | 新增敌机类型、道具、音效不应改动核心框架 |

## 6. 验收标准

1. 运行 `python plan_main.py` 能打开游戏窗口；
2. 方向键可控制英雄机移动且不超出屏幕边界；
3. 按空格能发射子弹，子弹向上飞行并自动消失；
4. 敌机每秒生成，子弹击中敌机后敌机播放爆炸动画并消失；
5. 敌机飞出屏幕自动销毁；
6. 无闪屏、无卡顿（维持 60 FPS）。

## 7. 需求优先级划分

| 优先级 | 需求 |
|--------|------|
| P0（必须） | F1~F10 全部基础玩法 |
| P1（重要） | F12 受击、F14 游戏结束、F15 计分 |
| P2（期望） | F11 自动连发、F13 生命值、F16 大型敌机血量 |
| P3（可选） | F17 道具、F18 暂停重开、F19 音效 |

# 飞机大战 开发文档

基于 `pygame` 实现的纵向卷轴射击小游戏，采用**精灵（Sprite）+ 精灵组（Group）**架构。

## 1. 项目结构

```
飞机大战/
├── plan_main.py          # 主程序：游戏入口、主循环、事件处理
├── game_sprites.py       # 游戏精灵模块：常量定义 + 全部精灵类
├── demo.py               # 独立演示脚本：角色动画帧切换示例（与主程序无耦合）
├── 需求文档.md            # 需求文档
├── 开发文档.md            # 本文档
└── images/               # 图片资源（详见附录 A）
```

## 2. 环境与运行

- 依赖：`Python 3` + `pygame`
- 安装：`pip install pygame`
- 运行：`python plan_main.py`
- 操作：
  | 按键 | 功能 |
  |------|------|
  | `←` / `→` | 左右移动英雄机（按住持续移动） |
  | `空格` | 发射子弹 |
  | 关闭窗口 | 退出游戏 |

## 3. 全局常量（`game_sprites.py`）

| 常量 | 值 | 含义 |
|------|-----|------|
| `SCREEN_RECT` | `(0, 0, 480, 700)` | 游戏窗口矩形（宽高全局唯一来源） |
| `FRAME_PER_SEC` | `60` | 目标帧率 |
| `CREATE_ENEMY_EVENT` | `pygame.USEREVENT` | 生成敌机定时事件（1000ms） |
| `HERO_FIRE_EVENT` | `pygame.USEREVENT + 1` | 英雄自动开火定时事件（500ms，已注册未处理） |

## 4. 类体系

```
GameSprite (基类: pygame.sprite.Sprite)
├── Background    # 滚动背景
├── Hero          # 英雄机
├── Bullet        # 子弹
└── Enemy         # 普通敌机
    └── BigEnemy  # 大型敌机（仅更换贴图与速度）
```

### 4.1 `GameSprite`（基类）
- 统一封装：加载图片 → `self.image`，按图片尺寸生成 `self.rect`，移动速度 `self.speed`；
- 动画帧速率参数 `self.animate_speed = 0.1`；
- `update()`：默认每帧 `rect.y += speed`（纵向移动）。

### 4.2 `Background`（背景）
- 双背景接力：`Background(is_alt=True)` 的第二张图初始置于屏幕正上方（`rect.y = -height`）；
- `update()`：两张图同步下移，移出屏幕底部后回到顶部，形成**无缝纵向滚动**。

### 4.3 `Hero`（英雄机）
- **动画**：`me1.png`/`me2.png` 双帧循环（`current_image` 以 0.1 步进累加，越界归零，取整后作为帧索引）；
- **移动**：`speed` 由主程序按键状态设置（右 3 / 左 -3 / 静止 0），水平越界钳制在窗口内；
- `fire()`：在英雄机顶部 `bullet.rect.bottom = self.rect.y`、水平居中处创建 `Bullet`，加入 `self.bullets` 组。

### 4.4 `Bullet`（子弹）
- 速度为 `-2`（向上飞）；
- 出屏清理：`rect.bottom < 0` 时 `kill()`；
- `check_collide(enemys)`：逐个与敌机 `colliderect` 碰撞检测，命中 → 子弹 `kill()`、敌机 `down()` 进入爆炸。

### 4.5 `Enemy`（普通敌机）
- 随机水平位置出生（顶部），速度 `random.randint(1, 3)`；
- **爆炸状态机**：`down()` 置 `isDown=True`；`update()` 中若 `isDown` 则按 0.1 步进播放 `enemy1_down1~3` 三帧动画，播完 `kill()`；
- 飞出屏幕底部（`rect.y >= 700`）自动 `kill()`。

### 4.6 `BigEnemy`（大型敌机）
- 继承 `Enemy`：换 `enemy2.png`、速度固定 1、使用 `enemy2_down1~3` 爆炸帧；
- **注意**：仅贴图与速度差异，无血量概念，`enemy2_hit.png` 受击帧未接入。

## 5. 主程序 `PlanGame`（`plan_main.py`）

### 5.1 初始化流程
1. `pygame.init()`，创建 480×700 窗口、60 FPS 时钟；
2. `__create_sprites()`：双背景组、敌机组（空）、英雄机及英雄组；
3. 注册定时事件：`CREATE_ENEMY_EVENT`（1000ms）、`HERO_FIRE_EVENT`（500ms）。

### 5.2 主循环 `start()`

```
while True:
    clock.tick(60)          # 1. 锁帧率
    __event_handler()       # 2. 事件处理
    __check_collide()       # 3. 碰撞检测
    __update_sprites()      # 4. 更新 + 绘制
    pygame.display.update() # 5. 刷新画面
```

### 5.3 事件处理 `__event_handler()`
| 事件 | 处理 |
|------|------|
| `QUIT` | 调用 `__game_over()` 退出 |
| `CREATE_ENEMY_EVENT` | 10% 概率生成 `BigEnemy`，否则 `Enemy`，加入敌机组 |
| `KEYDOWN + K_SPACE` | `hero.fire()` 发射子弹 |
| 按键轮询 | `keys_pressed` 设置英雄机 `speed`（左右/静止） |

### 5.4 更新与绘制顺序
背景 → 敌机组 → 英雄组 → 子弹组。后绘制覆盖先绘制，保证视觉层级：背景最底、敌机与英雄居中、子弹最上。

## 6. 关键机制

| 机制 | 实现方式 |
|------|----------|
| 背景滚动 | 双图接力轮换（`Background`） |
| 敌机生成 | `set_timer` 定时事件 + 10% 概率出大飞机 |
| 敌机爆炸 | `isDown` 标志 + 3 帧动画播完 `kill()` |
| 碰撞检测 | `Bullet.check_collide()`：子弹遍历敌机逐个 `colliderect` |
| 精灵回收 | 出屏 / 动画结束调用 `kill()`，从所有精灵组移除 |
| 英雄动画 | `current_image` 浮动累加取整切换双帧 |

## 7. 已知问题与优化建议

1. **`HERO_FIRE_EVENT` 未处理**：定时器已注册但 `__event_handler` 无对应分支，自动连发功能未生效；补 `elif event.type == HERO_FIRE_EVENT: self.hero.fire()` 即可。
2. **`Hero.fire()` 的 `for i in (0,)` 无意义**：等价于直接执行一次，为后续多路子弹预留的写法，可简化或扩展为列表。
3. **`Bullet.down_images` 为遗留代码**：加载了敌机爆炸帧但从未使用（疑为复制 `Enemy` 时带入），可删除。
4. **无失败判定**：英雄机与敌机碰撞、游戏结束均未实现，属半成品。
5. **碰撞检测为 O(子弹×敌机) 嵌套遍历**：可改用 `pygame.sprite.groupcollide` / `spritecollide` 提升效率。
6. **`BigEnemy` 差异化不足**：仅换贴图，建议接入血量与受击帧（`enemy2_hit.png`）。
7. **`demo.py` 为独立脚本**：演示动画帧切换，与主程序无耦合，可独立运行。
8. **`random` 概率写死**：`random.randint(0, 10) > 9` 即 10% 概率，建议提取为常量便于调整。
9. **`__game_over()` 直接 `exit()`**：教学代码可接受，工程化建议改为游戏状态机（运行/暂停/结束）管理。
